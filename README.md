# vgmplay
VGM file player for the BBC Micro.

The conclusions of my original explorations into VGM playback on the BBC Micro conducted in back in 2015-2016. This code has been long supercede by [vgm-converter](https://github.com/simondotm/vgm-converter) and [vgm-packer](https://github.com/simondotm/vgm-packer) by [simondotm](https://github.com/simondotm). It is added here purely as a curiosity / early reference.

See also the fantastic ongoing work by [NegativeCharge](https://github.com/NegativeCharge).
